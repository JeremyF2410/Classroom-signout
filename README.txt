INSTALL ON IPAD AIR 2
1. Open the GitHub Pages site in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Launch it from the Home Screen.
5. Enable Guided Access if required.

ZOOM CONTROL
This version disables pinch-to-zoom, gesture zoom and rapid double-tap zoom inside the app.
